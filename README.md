# 💰 Financial Wellness Buddy  
### AI-Powered Personal Finance & Investment Platform

An end-to-end AI-driven financial analytics system built with Streamlit.

This platform combines:

- 🔐 User Authentication
- 📊 Expense Analysis
- 📈 ARIMA & Prophet Forecasting
- 🎲 Monte Carlo Investment Simulation
- 🏖 Retirement Planning AI
- 📈 Live Market Data Integration
- 🤖 AI Financial Advisor Chatbot
- 🧠 Risk Profiling Engine
- 💎 Glassmorphism Professional UI
- ☁ Streamlit Cloud Deployment Ready

---

## 🚀 Live Features

### 🔐 Authentication System
- Secure login & registration
- Password hashing (SHA256)
- SQLite database storage

### 📊 Financial Dashboard
- Upload CSV financial data
- Expense & savings analysis
- Savings ratio calculation

### 📈 Forecasting
- ARIMA Time Series Forecast
- Facebook Prophet Forecast
- Future 6-month projections

### 🎲 Monte Carlo Simulation
- 500+ simulations
- Expected future portfolio distribution
- Risk-return modeling

### 🏖 Retirement Planning AI
- Calculates required retirement corpus
- Inflation-adjusted projections

### 📈 Live Market Data
- Real-time stock data using yfinance
- Interactive stock trend charts

### 🧠 Risk Profiling AI
- Risk level prediction (Low / Moderate / High)
- Portfolio allocation suggestions

### 🤖 AI Financial Chatbot
- Interactive financial advisor
- Investment & savings guidance
